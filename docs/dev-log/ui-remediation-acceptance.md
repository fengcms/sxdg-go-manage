## 验证

- `pnpm check`：TypeScript、Biome、53项单测、Vite构建通过。Biome保留5条info，无warning/error。
- 全套 Chromium：16项通过，包含四角色全部授权页及原业务写入链路，另有亮暗截图、200/64/56/52px几何断言、筛选对齐、390/1024/1280/1440宽度、键盘主题切换、菜单焦点与未保存弹窗检查。
- 截图基线在 `tests/visual.spec.ts-snapshots/`，动态区样式在 `tests/visual-mask.css`；新增基线已经目视检查，随后普通验证通过。更换操作系统/字体环境时需重新核对平台基线，不得无条件更新忽略差异。
- 启动命令不变：后端正常运行后，本仓库 `./start.sh`，访问 http://127.0.0.1:5173。纯内存登录机制保持，页面刷新需重登。
- 业务夹具准备与测试步骤仍见根目录 README；反复跑写入验收应重新创建隔离账号及记录。

## 取舍与边界

- 本次对齐风格和页面模式，并非把电销业务复制过来。接口、后端表、四角色权限、资金/订单约束和消息参与权限不变。
- 分类仍展示完整父链，没有新增拖拽或折叠树；模板为JSON编辑加交互预览。系统参数按用途和生效说明呈现，未新增后端分组接口。
- 输入/下拉统一样式但保留原生选择语义；日期中文入口后调用系统日历，弹层语言随浏览器。这与参考的自绘日历实现不同，避免在此次视觉调整中新增日期业务规则。
- 保留局部重试，未照抄参考的整页reload；主题和折叠偏好可持久化，令牌和业务数据不持久化。
- 本轮浏览器为Chromium；Safari/Firefox与生产部署仍未验收。外部微信、支付和IM仍为mock，未新增IM发送、新看板指标或其他后台业务。
