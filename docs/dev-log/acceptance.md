## 启动与复核

1. 后端使用包含 a2085e1 及密码登录、服务费配置前置提交的版本，运行其 `./start.sh start`。
2. 本仓库 Node 22.14.0 / pnpm 9.4.0，`pnpm install --frozen-lockfile` 后 `./start.sh`。
3. 打开 http://127.0.0.1:5173，使用后端已有管理员账号。初始化及验收命令见 [README](../../README.md)。
4. 刷新页面要求重新登录是纯内存会话设计；筛选 URL 保留。

## 边界与后续工作

- 未覆盖 Safari/Firefox 和真实生产设备矩阵；自动化通过不代表穷尽全部字段组合与网络竞争。
- 退款通过金额边界有前端测试，本轮实际写入采用驳回；真实支付退款需供应商凭据和联调环境。
- 分类以全分页父链路径呈现，没有折叠树控件；动态模板是 JSON 编辑加交互预览，无拖拽设计器。
- IM 仅已入库消息查询和会话转接，没有发送、供应商完整历史和实时已读；新版看板、管理员页面开户、任务/勋章/活动运营不在范围。
- 域名、HTTPS、生产反代与 SPA 回退、发布回滚和真实服务凭据留部署阶段。
- 决策、踩坑与修复过程见 [流水账](2026-10-04.md)。
