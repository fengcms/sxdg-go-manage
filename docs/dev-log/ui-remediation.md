# UI 整改流水账与规格

## R0 — 样板规格
- 以用户提供的 telemarketing-saas-manage 源码为视觉依据，保留四系点工业务及安全契约。
- 蓝灰色明暗令牌，侧栏 200/64px，顶栏 56px，内容 padding 24px；14px 正文控件、36px 常规控件、32px 行操作、移动主操作44px。
- 用户列表、详情摘要、调分/封禁弹窗是样板；随后推广全模块。用户已授权全程实施，内部截图检查后继续，不重复等待批准。
- 组件圆角采用参考代码分级（按钮6、输入8、卡片12），不机械套用旧指导统一10px。
- 保留既有 API、权限、纯内存会话、金额、状态机和未保存保护；主题/折叠偏好独立存储。
- 加载/空/错/长文本/亮暗/390至1440宽度列入验收。参考源码中的表格 sticky 注释不等于实现，实际单独实现。
- 原页面截图已在上一轮审阅；本阶段采用已核对源码尺寸作为起点，完成后渲染截图检查。

## R1 — 基础层
- 换成参考的蓝灰令牌并提供明暗模式；只保存 UI 偏好，访问令牌仍纯内存。
- 导航改 200/64px、顶栏56px，业务独立图标，选中与悬停分离；主区独立滚动。移动菜单沿用可访问关闭按钮。
- 拆出按钮、状态、弹窗组件，标准控件36px，表格操作32px；全局表格选择器改为作用域内，避免污染预览。
- 未额外升级依赖；Radix 继续负责弹窗焦点。日期和分页留 R2，复杂详情留 R3。
- pnpm check 全部通过，44项单测通过。

## R2 — 用户列表样板
- 筛选单独成卡，按钮按输入底边对齐；日期入口中文占位，仍可打开系统日期选择器，不改变年月日参数。
- 表格局部滚动、真实 sticky 表头、52px标准行，分页独立可见；增加首末页和有界页码窗口，避免大页数创建大量按钮。
- 用户昵称加入首字头像与长文本截断，账号状态用成功/危险标签；封禁使用低强调危险按钮。
- 补同结构骨架、区分无结果和暂无数据、保留局部重试，避免整页 reload 退出登录。
- pnpm check 通过，新增4项分页边界用例，总计48项单测通过。

## R3 — 详情与表单
- 弹窗按字段复杂度选择460/600/900px；移除每窗重复的泛化提示，确认阶段保留审计说明，危险操作使用红色与影响提醒。
- 用户操作显示昵称、ID及当前信用分，交易操作显示单号；详情增加身份/订单摘要和分组，金额以等宽数字强化。
- 用户子资源用真正切换内容的页签外观；未保存保护、后台错误回显、字段校验和二次确认保持。
- 标题固定、正文滚动，长表单底部操作粘住；状态从详情字段移到摘要，避免重复状态影响阅读及测试定位。
- pnpm check 通过，48项单测通过。

## R4 — 全模块推广
- 资质、内容、信用规则、客服与交易采用明确状态色；未知状态中性，不把未知封禁显示正常。
- 分类显示等级/名称/父链，Banner表格加预览；长名称允许换行，删除操作降为危险文本样式。
- 客服增加会话选中态和独立消息滚动；审计先中文摘要，原始变更折叠展开，避免技术数据占满首屏。
- 看板补指标图标、单位、刷新及业务口径，未添加无数据支持的趋势；登录随同主题统一。
- 账户信息下拉及提示按参考工作台补齐，退出仍直接可达。通知也随主题切换。
- pnpm check通过，48项单测通过；CSS存在4条选择器顺序提示，最终清理验证时处理。

## R5 — 视觉与业务验收、最后修整
- 隔离渲染了参考项目真实 PageHeader/Button/StatusTag/DataTable，未连接参考业务服务，也没改参考仓库。临时 Vite 的 /tmp 与 /private/tmp 路径及外部 Tailwind @source 导致首次缺样式，显式指定源后对照成功。
- 手机隐藏菜单增加 inert、焦点约束及 Escape 返回触发按钮。中屏原媒体样式强制64px，会让手动展开无效，改为进入断点自动收起，仍允许手动展开。
- 检查真实截图发现窄表格行操作折行把行撑高，改行操作不换行、由局部横滚承接；账户头像在手机保留。
- 补系统参数用途/生效范围，模板JSON编辑与预览桌面并排、手机单列，避免复杂编辑器继续纵向堆叠。
- 截图脚本一开始只等通用 h1，可能拍到前一页或骨架；改为等目标标题和具体数据区域后重新截图，旧截图不作验收证据。
- 视觉测试首次尺寸断言撞上侧栏动画，改轮询实际宽度；新增中屏手动展开测试，避免只看桌面。
- Playwright当前断言接受stylePath而非style；按类型修正动态区截图样式。注入样式后明确断言单元格隐藏，截图结束恢复，真实字段仍由业务测试验证。Node类型没有remove方法，改parentNode.removeChild后类型检查通过。
- 截图基线新建/调整后人工看了用户样板、暗色、弹窗，并使用普通模式重新验证；不把更新基线命令本身当成回归通过。
- 真实浏览器完整16项通过（34.3秒），包含原14项业务和2项视觉/键盘测试；最后模板及配置展示调整后补跑页面/视觉回归。隔离业务批次7b3a0409，审计记录保留。
- pnpm check通过：9个单测文件53项；Biome无warning/error，有5条非阻断info。后端及参考仓库工作树均无改动。
- 本轮没有新增包或改变接口。日期/下拉继续使用原生能力并统一外壳，系统日历弹层语言取决于浏览器；不是完整复制参考的自绘日历。没有新增图表口径或IM发送。
