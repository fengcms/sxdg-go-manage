## 2. 订单详情 `/orders/:id`

### 2.1 顶部摘要

| 字段 | 说明 |
|------|------|
| 订单号 | |
| 状态 | 大字号徽标 |
| 金额 | 大字号 |
| 下单时间 | |
| 来源 | Service / Requirement + 标题 |
| 交付方式 | 到店 / 线下 / 线上 |

### 2.2 右上角操作（仅 customer_service / super_admin）

- **修改订单状态**：下拉选择目标状态，需填写原因，二次确认
  - 后端 `PUT /api/v1/admin/orders/:id/status`
  - 仅允许特定状态流转（后端校验，前端给出可选项）

### 2.3 Tab 分区

| Tab | 内容 |
|-----|------|
| 基本信息 | 雇主 / 服务者信息、服务内容、预约时间、服务地点、金额明细 |
| 履约记录 | 打卡记录（上班卡 / 下班卡 / 状态上报，含 GPS 与照片） |
| 状态时间轴 | 全状态变更记录（`order_status_logs`） |
| 退款记录 | 该订单的退款单列表（如有） |
| 评价 | 雇主评服务者 / 服务者评雇主 |

### 2.4 金额明细

展示订单金额构成：

| 项目 | 金额 |
|------|------|
| 订单总额 | ¥xxx.xx |
| 平台服务费 | ¥xx.xx（5%） |
| 服务者实得 | ¥xxx.xx |

## 3. 退款审核 `/refunds`

> finance / customer_service / super_admin 可查看；审核操作仅 finance / super_admin。

### 3.1 筛选栏

| 筛选项 | 类型 | 说明 |
|--------|------|------|
| 关键词 | 输入框 | 退款单号 / 订单号 |
| 退款状态 | 下拉 | 全部 / 处理中 / 已同意 / 已拒绝 / 平台审核中 / 已完成 / 已撤销 |
| 申请人角色 | 下拉 | 全部 / 雇主 / 服务者 |
| 申请时间 | 日期范围 | |

### 3.2 表格列

| 列 | 说明 |
|----|------|
| 退款单号 | 点击跳转详情 |
| 关联订单 | 订单号 + 金额 |
| 申请人 | 头像 + 昵称 + 角色 |
| 退款金额 | |
| 状态 | 状态徽标 |
| 申请时间 | |
| 操作 | 审核（仅处理中/平台审核中状态）/ 查看 |

│ 退款金额：¥200.00                         │

### 3.4 审核操作

| 操作 | 接口 | 权限 |
|------|------|------|
| 同意退款 | `POST /api/v1/admin/refunds/:id/approve` | finance / super_admin |
| 拒绝退款 | `POST /api/v1/admin/refunds/:id/reject`（需原因） | finance / super_admin |

> 后端退款状态机详见 `enums.md §6`。

## 5. 需求管理 `/requirements`

与服务管理结构相同，字段差异：

| 差异项 | Requirement |
|--------|-------------|
| 发布者 | 雇主 |
| 状态 | 草稿 / 待支付 / 已发布 / 已关闭 |
| 金额 | 预付金额 |
| 接单情况 | 已接单人数 / 需求人数 |

操作：下架 / 恢复上架 / 删除。

## 6. 后端接口契约摘要

### 订单

| 方法 | 路径 | 说明 |
|------|------|------|
| GET | `/api/v1/admin/orders` | 列表（status/source_type/delivery_type/start_date/end_date/page/page_size） |
| GET | `/api/v1/admin/orders/:id` | 详情（含履约记录、状态日志） |
| PUT | `/api/v1/admin/orders/:id/status` | 修改状态（target_status, reason） |

### 退款

| 方法 | 路径 | 说明 |
|------|------|------|
| GET | `/api/v1/admin/refunds` | 列表 |
| GET | `/api/v1/admin/refunds/:id` | 详情 |
| POST | `/api/v1/admin/refunds/:id/approve` | 审核通过 |
| POST | `/api/v1/admin/refunds/:id/reject` | 审核拒绝（reason） |

### Service / Requirement

| 方法 | 路径 | 说明 |
|------|------|------|
| GET | `/api/v1/admin/services` | 列表 |
| GET | `/api/v1/admin/services/:id` | 详情 |
| PUT | `/api/v1/admin/services/:id/status` | 上下架 |
| DELETE | `/api/v1/admin/services/:id` | 删除 |
| GET | `/api/v1/admin/requirements` | 列表 |
| GET | `/api/v1/admin/requirements/:id` | 详情 |
| PUT | `/api/v1/admin/requirements/:id/status` | 上下架 |
| DELETE | `/api/v1/admin/requirements/:id` | 删除 |
