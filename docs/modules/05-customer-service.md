# 模块五：客服管理

> 状态：规划初稿
> 创建日期：2026-10-04
> 后端接口：`/api/v1/admin/cs/agents`、`/api/v1/admin/cs/sessions`

---

## 1. 客服账号 `/cs/agents`

> 仅 super_admin 可创建/编辑客服账号。

### 1.1 列表

| 列 | 说明 |
|----|------|
| 客服昵称 | |
| 关联用户 | 绑定的用户账号（头像 + 昵称） |
| 在线状态 | 在线 / 离线 徽标 |
| 最大并发 | 同时接待会话上限 |
| 当前接待数 | 实时 |
| 启用状态 | 启用 / 停用 |
| 操作 | 编辑 / 切换在线状态 |

### 1.2 新建/编辑

| 字段 | 说明 |
|------|------|
| 关联用户 | 搜索用户（必须是已注册用户） |
| 客服昵称 | 前台展示给用户的称呼 |
| 头像 | 可选，默认用用户头像 |
| 最大并发数 | 默认 10 |
| 启用状态 | 开关 |

### 1.3 在线状态切换

客服可自行在后台切换「在线 / 离线」（customer_service 角色可操作自己的）。
- 在线：可被分配新会话
- 离线：不再分配新会话，已接待的会话可继续处理

## 2. 接待会话 `/cs/sessions`

> 仅 customer_service / super_admin 可访问。

### 2.1 页面布局

经典客服工作台：左侧会话列表 + 右侧聊天窗口。

```
┌──────────────┬───────────────────────────────────┐
│ 🔍 搜索会话    │  会话：与用户「李四」的对话         │
│              │                                   │
│ ┌──────────┐ │  [10:00] 用户：你好，我想咨询...     │
│ │李四 10:05│ │  [10:01] 客服：您好，请问有什么...   │
│ │ 最后一条… │ │  [10:02] 用户：...                 │
│ └──────────┘ │                                   │
│ ┌──────────┐ │                                   │
│ │王五 09:30│ │                                   │
│ │ ...      │ │                                   │
│ └──────────┘ │                                   │
│              │                                   │
│              ├───────────────────────────────────┤
│              │ [输入消息____________] [发送]       │
│              │ [📎 发送订单卡片] [📎 发送服务卡片]   │
└──────────┴───┴───────────────────────────────────┘
```

### 2.2 会话列表

| 项 | 说明 |
|----|------|
| 用户头像 + 昵称 | |
| 最后消息预览 | 截断显示 |
| 最后消息时间 | |
| 未读标记 | 红点 |
| 关联订单 | 如有订单关联，显示订单号标签 |

### 2.3 聊天窗口

- 消息类型：文本、图片、系统卡片、订单信息卡片
- 支持发送订单卡片（将当前用户的订单以卡片形式发送，用户点击可跳转订单详情）
- 支持快捷回复（二期，首期可预留）

### 2.4 会话流转

- 右上角「流转」按钮，打开客服选择下拉，将会话转给其他在线客服
- 接口：`POST /api/v1/admin/cs/sessions/:conv_id/transfer`

## 3. 技术实现要点

1. **实时消息**：客服消息通过腾讯 IM SDK 或 WebSocket 推送。前端需监听新消息事件，自动追加到聊天窗口并更新会话列表。
2. **会话列表拉取**：`GET /api/v1/admin/cs/sessions` 返回当前客服接待中的会话。
3. **历史消息**：`GET /api/v1/conversations/:id/messages` 分页滚动加载。
4. **已读回执**：进入会话后调用 `POST /api/v1/conversations/:id/messages/read` 标记已读。

> 客服聊天的实时能力依赖后端 IM 集成。开发前需确认后端是否已集成腾讯 IM，以及消息推送的技术方案（WebSocket / 长轮询 / 第三方 SDK）。

---

## 4. 后端接口契约摘要

| 方法 | 路径 | 说明 | 权限 |
|------|------|------|------|
| POST | `/api/v1/admin/cs/agents` | 新增/编辑客服账号 | super_admin |
| POST | `/api/v1/admin/cs/agents/:id/status` | 切换在线/离线 | customer_service / super_admin |
| GET | `/api/v1/admin/cs/sessions` | 我的接待中会话 | customer_service / super_admin |
| POST | `/api/v1/admin/cs/sessions/:conv_id/transfer` | 流转会话 | customer_service / super_admin |
| GET | `/api/v1/conversations/:id/messages` | 历史消息 | customer_service / super_admin |
| POST | `/api/v1/conversations/:id/messages/read` | 标记已读 | customer_service / super_admin |

> 注：`conversations` 与 `messages` 接口复用用户端消息中心接口，客服角色可访问所有用户的会话（后端需做客服身份豁免）。
